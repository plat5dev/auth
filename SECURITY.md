# Security Policy

## Supported Versions

Security fixes are released for the latest minor version line of Plat5 Auth (`v*` release tags). Pin deployments to an explicit release tag or image digest and stay current with patch releases.

> **Note:** Plat5 Auth is a lightweight reference OAuth 2.0 issuer for local development and simple setups. For enterprise or compliance-scoped deployments requiring SAML federation, MFA/passkeys, SCIM, or lockout policies, point Plat5 at a dedicated enterprise IdP.

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Please report vulnerabilities privately using [GitHub Private Vulnerability Reporting](https://github.com/plat5dev/auth/security/advisories/new).

Include as much detail as possible to help reproduce and assess the issue:

- Affected version/tag
- Step-by-step reproduction instructions or proof of concept
- Potential impact and any suggested mitigation

## Response Process

- We aim to acknowledge private reports within 3 business days.
- Once validated, we will work on a fix and coordinate disclosure with you before publishing a security advisory and patched release.
